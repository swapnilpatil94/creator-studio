# 100 hidden-system topics (one short a day)

How to use: each row is an IDEA, not a script. The Writer only uses facts you give it, so before a topic goes in the queue, open the anchor source, copy 4-5 plain facts (what was done, the numbers, the result) into the topic, and add the link to `verify`. Anchors are named from memory, so check them. "check" = I am not sure of the source or the numbers; find one or drop the topic. Title style: accuse a hidden culprit, 2-3 big words on the thumbnail.
