# Languages and world mythology (2026-10-18)

**How it works.** Hindi is the source language (served at `/`). Other languages live at `/<code>/` (`/en/`, `/mr/`, `/es/`, ...). A language appears on the site (pages, switcher, hreflang, RSS, sitemap) only when it has at least one published translated post, so an unfinished language never shows an empty site.

**Who translates:** the studio, not a person: `tools/content/translate.mjs` uses the writer model (Anthropic API if `ANTHROPIC_API_KEY` is set, else local Ollama). Each translation is checked (target script, no leftover Hindi, length, same number of headings, numbers kept, title <= 110 and description <= 160 characters) and retried with the problems fed back; failures go to `content/rejected/` and are never published. Hub: Carousel -> Video tab, "Languages" card, or:
```
node tools/content/translate.mjs --lang en,mr --slug ganga-seven-sons   # posts -> content/items/<slug>.blog.<lang>.json
node tools/content/translate.mjs --lang en --ui                         # site interface text -> site/src/i18n/gen/en.json
node tools/content/to-mdx.mjs                                           # items -> MDX (translations go to site/src/content/blog/<lang>/)
```
Every translated page says "machine translated" and links to the Hindi original; `hreflang` alternates and `x-default` (Hindi) are in the head; the news sitemap lists each language.

**Quality, honestly.** A local 14B model is good into English, acceptable into Spanish, Portuguese, Indonesian and Marathi, and weak into Tamil, Telugu, Bengali and Gujarati. Use an Anthropic key for those, and have a native reader sample a few posts before promoting a language. The static pages (about, editorial policy, corrections, privacy, contact) stay Hindi-only for now.

**Foreign mythology.** New section `world` ("World mythology") and pillar `world-myths`. Five topics are queued with status `needs_corpus` (Persephone, Prometheus, Odin, Osiris and Isis, the flood in Manu/Noah/Utnapishtim). The writer cannot draft them until their public-domain source texts are in the corpus (`tools/content/corpus.mjs`: add Bulfinch "The Age of Fable", the Prose Edda, Eggeling's Shatapatha Brahmana, Genesis, Gilgamesh tablet XI), because the QA gate requires every claim to be found in the retrieved passages. Same rule as for Indian stories: each tradition on its own terms, no ranking of faiths.
