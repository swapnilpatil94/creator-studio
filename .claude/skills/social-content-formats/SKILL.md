# Social content formats (docs/CONTENT_PLAN.md)
- **FB text (11:00):** hook ≤10 words (question + detail) · 2-4 short lines, answer withheld · one open question + invite to save · source line · 3 hashtags · no link.
- **Carousel (11:00, IG+FB):** 1080×1350 JPEG; slide 1 hook; slides 2-9 one fact (≤14 words); last slide one action (save/follow @kathaaya.stories); text-only by default; first image sets the ratio on Instagram; max 10 slides (official).
- **Reel/Short (19:00):** same file to IG, FB, YT; FB Reels 3-90 s 9:16; set a cover on every one.
- **FB long (20:00 Mon/Wed/Fri):** 3-4 min cut of the Sunday film's chapters. **YT long (Sunday):** chapters (first 0:00, ≥3, ≥10 s), credits, pinned comment.
- **Blog:** 700+ words, H1 + ≥3 H2, FAQ from real questions, sources + tradition note, Article schema.
- Pillars: unsaid relations, saveable lists, banned facts/what-ifs, family moral, belief-and-place. Modern-parallel only inside sourced long-form.
- Evidence levels: official limits are hard rules; posting times and "X% more saves" are hypotheses to test with `tools/content/insights.mjs` for 4 weeks.
