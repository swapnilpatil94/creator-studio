# Theme: documentary (investigative, premium)
Dark neutrals as the base (obsidian #121416, graphite #303438), warm amber #C18A45 for discoveries and evidence, signal red #B93A36 sparingly for pressure, warm ivory #F0E9DC for text, muted sage #64736B for secondary information.
Photographic plates are graded once (warm highlights, cool shadows, light vignette, no heavy grain) and always labelled ILLUSTRATIVE RECONSTRUCTION. Motion graphics (choice trees, timelines) are drawn in code. Captions: Mukta 800, ivory with the key word in amber, no outline.
Palette roles map onto the shared keys: night = obsidian, maroon = graphite, saffron/gold = amber, indigo = sage.
